# Project metadata

This directory contains the structured records used to cross-reference experimental runs, environmental configurations, and validated FRA/DC files.

## Current files

### `PV_Lab_Master_Log.xlsx`

Authoritative current laboratory run log supplied for the final repository.

Sheets:

- `Run Log` — experimental run register and recorded measurement metadata.
- `Field Guide` — field definitions / usage guidance.

SHA-256:

`0e4d1976c241ae3eb2e6c0204a7dedb7dff8b4b08a0486745de145f4257b323a`

### `PV_Environmental_Rig_Characterisation_Tracker.xlsx`

Environmental-rig configuration workbook used during controlled irradiance/temperature characterisation.

It contains setup/configuration sheets and a summary sheet covering the environmental-rig mapping campaign.

SHA-256:

`2dda6341906302286a2638d9cb548ef636efadabf9b33c18e9c7c70dac9014a0`

### `PV_Validated_FRA_Crosswalk_20260917.xlsx`

Validated crosswalk used by the feature-extraction workflow to associate FRA, DC and environment records.

## Archived backups

`archive/` contains two earlier master-log backups retained for provenance. They are **not** the authoritative log used by the final report scripts.

The current `PV_Lab_Master_Log.xlsx` should be used for reproduction.
